# Data dictionary: ARDE/KUBAHO workbook mode

_Generated by `src/arde_pipeline.py` from the database schema. Column names and meanings only, no data. The database itself is `data/real/warehouse/arde_workbook.duckdb` (gitignored)._

Columns copied from the workbook keep the workbook's meaning (headings mapped in `config/arde_format.yaml`). Added columns are described below. Every fact row has its lineage (source_file, source_sheet, source_row).
